BRANCH COMPARISON: electronjs vs main
AI-VTUBER-Twitch-Chat-Bot Repository
================================================================================

EXECUTIVE SUMMARY
-----------------
The electronjs branch represents a major strategic shift from a web-based 
application to a desktop application using Electron framework. This change 
results in a 17% code reduction (1,339 lines) while focusing on core features.

KEY STATISTICS
--------------
• 208 commits ahead of main branch
• 25 files changed
• +946 lines added, -2,285 lines removed
• Net code reduction: 58% in modified files
• Development period: Feb 8-15, 2025

MAJOR ARCHITECTURAL CHANGE
--------------------------
main Branch:       Web Browser → Flask Server (Ollama + Gemini)
electronjs Branch: Electron Desktop App → Multiple Processes (Ollama Only)

NEW FEATURES IN ELECTRONJS
---------------------------
✅ Electron Desktop Application
   - Native window management
   - Automatic process spawning (Flask, Speech Server)
   - Better system integration
   - Clean shutdown handling

✅ Custom Speech Recognition Server (speechServer.js)
   - Puppeteer-based speech recognition
   - Runs on separate port (3000)
   - Better reliability than browser native
   - Improved reconnection logic

✅ Enhanced Screen Capture
   - Electron desktopCapturer API
   - Window/monitor selection with thumbnails
   - Multiple fallback strategies
   - Better protected content handling

REMOVED FEATURES FROM MAIN
---------------------------
❌ Google Gemini AI Provider
   - No cloud AI option
   - No vision/image analysis
   - No function calling
   - Ollama-only implementation

❌ Computer Control Module (484 lines)
   - File operations
   - Command execution
   - Web scraping
   - Application launching

❌ Conversation History UI (114 lines)
   - History viewing modal
   - Per-user tracking
   - History management

❌ Simplified RAG System
   - Removed FAISS + BM25 hybrid
   - Basic functionality only

BREAKING CHANGES
----------------
Configuration Changes:
• Removed: AI_PROVIDER, GEMINI_API_KEY, GEMINI_MODEL, ENABLE_COMPUTER_CONTROL
• Required: Node.js and npm installation
• Launch: npm start (instead of python app.py)

Dependency Changes:
• Added: electron, express, puppeteer, socket.io (Node.js)
• Removed: google-generativeai, Pillow (Python)

API Changes:
• Screen capture now uses Electron IPC
• Speech recognition through dedicated socket server
• No more Gemini API endpoints

RECOMMENDATION
--------------
Choose MAIN branch if you need:
☁️  Cloud AI with vision capabilities
🖼️  Image analysis features
📜 Conversation history
🖥️  Computer control (experimental)
🌐 Web deployment

Choose ELECTRONJS branch if you need:
🖥️  Desktop application
🔒 Local-only AI (privacy)
🎯 Simpler codebase
📦 Easier maintenance
🚀 Production-ready stability

CONCLUSION
----------
electronjs = Production-Ready Desktop App (Stability over Features)
main       = Feature-Rich Web App (Flexibility over Simplicity)

The electronjs branch trades experimental features for a more maintainable,
production-ready codebase focused on core VTuber chatbot functionality.
